# BossBattle

UE5とC++を用いて制作しているFPS視点のソードアクションゲームです。

## 使用技術
- Unreal Engine 5
- C++
- Blueprint

## 実装内容
- マウス入力を利用した一人称視点の剣制御
- Behavior Treeによる敵AI
- 内積を利用したパリィ判定システム
- Niagaraによるエフェクト
- ヒットストップ演出
- プレイヤー・敵HPのUI作成

## 操作方法
- W/A/S/D：プレイヤー移動
- 右クリック：剣構え
- マウス移動：剣操作/攻撃

## 制作目的
ゲームプログラマー就職活動向けの個人制作作品
